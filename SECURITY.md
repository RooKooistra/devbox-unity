# Security Policy

DevBox Unity installs development tools and configures desktop integration. Security and transparency matter.

## Supported Versions

Security fixes will target the latest released version of DevBox Unity.

## Reporting a Vulnerability

Please open a private security advisory on GitHub when available, or contact the maintainer directly.

## Security Principles

DevBox Unity should:

- Avoid unnecessary network calls.
- Avoid telemetry.
- Avoid collecting personal information.
- Avoid modifying the host system unless clearly explained.
- Ask before destructive actions.
- Prefer official repositories and vendor sources.
