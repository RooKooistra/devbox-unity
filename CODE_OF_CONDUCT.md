# Code of Conduct

DevBox Unity is intended to be welcoming to developers of all experience levels.

## Expected Behaviour

- Be respectful.
- Be patient with newcomers.
- Explain assumptions.
- Focus on solving the problem.
- Prefer constructive feedback.

## Unacceptable Behaviour

- Harassment or personal attacks.
- Gatekeeping based on experience level.
- Dismissive responses to beginner questions.
- Intentionally disruptive behaviour.
